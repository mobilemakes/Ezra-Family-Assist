## Complaint Escalation Path

```
1. Speak with Charge Nurse or Social Worker at facility
        ↓ (if unresolved within 3–5 days)
2. Submit written complaint to Facility Administrator
        ↓ (if unresolved within 7–14 days)
3. File complaint with ESRD Network
        ↓ (simultaneously or if urgent)
4. File complaint with State Survey Agency
        ↓ (for billing fraud or Medicare issues)
5. File complaint with CMS
        ↓ (for HIPAA or discrimination)
6. File complaint with HHS Office for Civil Rights
        ↓ (if physician misconduct suspected)
7. File complaint with State Medical Board
```
